# 🔁 Prompts Reutilizáveis para o NotebookLM

Prompts prontos para reutilizar sempre que precisar revisar um contrato de locação ou tirar uma dúvida rápida, usando as fontes já carregadas no notebook.

## Revisão de contrato
```
Com base nas fontes carregadas, analise o seguinte trecho de contrato de locação
residencial e aponte se há alguma cláusula que contraria a Lei 8.245/91,
citando o artigo correspondente:

[cole aqui o trecho do contrato]
```

## Checagem de garantia locatícia
```
Segundo a Lei 8.245/91, quais são os limites e obrigações legais da garantia
"[caução / fiador / seguro-fiança / cessão fiduciária]"? Cite o artigo exato.
```

## Simulação de cenário de inadimplência
```
Um locatário está há 2 meses sem pagar o aluguel. Com base nas fontes,
explique passo a passo o procedimento legal que o locador pode seguir,
citando os artigos da Lei 8.245/91 aplicáveis a cada etapa.
```

## Resumo rápido de um artigo específico
```
Resuma em linguagem simples o que diz o art. [número] da Lei 8.245/91,
e explique na prática o que isso significa para o locador e para o locatário.
```

## Comparação de opções
```
Compare, em formato de tabela, as opções de garantia locatícia previstas na
Lei 8.245/91 (caução, fiador, seguro-fiança, cessão fiduciária), considerando:
custo, complexidade, e nível de proteção para o locador.
```

## Verificação de cláusula abusiva
```
A cláusula abaixo é válida segundo a Lei 8.245/91 e a jurisprudência dominante,
ou pode ser considerada abusiva/nula? Justifique citando a fonte:

[cole aqui a cláusula]
```

## Atualização do glossário
```
Liste todos os termos técnicos jurídicos usados nesta fonte relacionados a
locação residencial, com uma definição simples para cada um.
```

> 💡 Dica: ao reutilizar esses prompts, sempre peça para a IA citar o artigo/fonte exata — isso reduz alucinação e facilita a checagem posterior.
